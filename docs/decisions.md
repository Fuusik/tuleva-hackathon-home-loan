## Superseded presentation

The v5.1 source visibility fix exposed prefilling from the old first step. V6 replaces those separate goal/data/source/review modes with one continuous form. Source possibilities remain visible beside fields and in a compact Applicants overview; source examples are expandable. Historical example code, fixtures and documentation have been removed rather than moved to another view. User-entered offer version history remains a distinct current feature.

## Collaboration and open decisions
