# Anonymised historical demo cases

Read from an owner-authorised private loan case study on 10 October 2026. Public code contains only selected historical terms and synthetic/explicit assumptions, no private email URLs, identities, account numbers or property addresses. Source emails remain private, so this document does not provide independently accessible bank confirmation. All terms are historical and concern one household, not a representative market sample.

## Other findings and boundaries

The private report documents an omitted 45-day special term in a 2014 SEB draft, later acknowledged by the bank. Manual contract comparison illustrates checking such promises; no automatic legal analysis is made. Historical statement periods (including a 2020 SEB twelve-month request) and separate co-applicant application/consent steps must not be treated as current mandatory rules. The current public-source matrix keeps its evidence date and verification gaps.

Budget/property/profile values and benchmark/reset choices used to demonstrate the cases are modelling assumptions. Benchmark period/reset are marked assumed in the public data unless separately supplied. Other insurance, account, transaction and exit costs remain unknown, rather than invented actual prices. Source dates, decision/evidence status and inherited fields remain visible; correcting them in the UI produces manually edited demo terms.

One negotiation round can be simulated from these examples; it sends nothing and does not prove this service caused historical improvements. No generic €10,000+ saving, average-client benefit, guaranteed €99 payback, current bank rate or service pricing is established.
